ROTAS PRINCIPAIS DA API
Login:
POST /api/Auth/login

Validar autenticacao:
GET /api/Auth/authenticate

Listar contatos:
GET /api/User

Consultar contato:
GET /api/User/{id}

Cadastrar contato:
POST /api/User

Editar contato:
PUT /api/User/{id}

Alterar propria senha:
PATCH /api/User/me/password

Remover contato:
DELETE /api/User/{id}
